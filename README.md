## 👋 About Me
I’m a robotics engineer passionate about building reliable robotic systems — from low-level device drivers to high-level motion planning.  
I work across mechanical, electronics, and software domains to create practical, production-ready solutions.

- 🔧 Focused on **robotic grippers, motion control, and ROS 2 integration**
- 📦 Contributor & maintainer of open-source robotics packages
- 🚀 Interested in bridging simulation and real-world robotics
- 🌱 Always exploring embedded systems, control algorithms, and industrial automation

---

## 🏆 Featured Projects

- **[DELTO_M_ROS2](https://github.com/Tesollo-Delto/DELTO_M_ROS2)**  
  ROS 2 package for DELTO grippers, providing topic-based and `ros2_control` interfaces for Modbus/TCP.  
  *C++ • ROS 2 • ros2_control*

- **[DELTO_B_ROS2](https://github.com/Tesollo-Delto/DELTO_B_ROS2)**  
  ROS 2 driver for DELTO B-series grippers.  
  *C++ • ROS 2*

- **[modern_robotics_rs](https://github.com/CottontailRabbit/modern_robotics_rs)**  
  Rust port of the Modern Robotics library, developed alongside a robotics study group.  
  *Rust • Robotics Mathematics*

- **[LX16A_RUST](https://github.com/CottontailRabbit/LX16A_RUST)**  
  Rust interface for LX-16A serial servos.  
  *Rust • Embedded Systems*
